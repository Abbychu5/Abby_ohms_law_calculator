# Ohm's Law and Power Calculator

## What it does
This program allows users to calculate electrical parameters (Voltage, Current, Resistance, or Power) using Ohm's Law and power formulas. It features continuous execution through a menu loop and handles invalid inputs or division-by-zero errors gracefully.

## How to run it
Install Python 3, then run: python ohms_law.py

I added a Calculation History feature that stores previous successful computations in a list, allowing users to review their session history at any time.
